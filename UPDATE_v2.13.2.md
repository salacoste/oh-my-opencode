## 🆕 Что нового в v2.13.2 (6 января 2026)

### Исправления

1. **Исправление рекурсивных subagents** (#536)
   - Исправлена проблема, когда background agents создавали рекурсивные subagents через `call_omo_agent`
   - Теперь предотвращается бесконечная рекурсия при вызове агентов

2. **Политика английского языка и шаблоны GitHub issues** (#534)
   - Добавлена политика использования английского языка
   - Добавлены шаблоны для GitHub issues

## 🆕 Что нового в v2.13.1 (5 января 2026)

### Основные функции

1. **Новая команда `/refactor`** — Интеллектуальный рефакторинг
   
   Команда `/refactor` работает как опытный инженер:
   
   - **Понимание кодовой базы**: Запускает параллельные explore агенты для анализа зависимостей, паттернов использования и архитектурных границ
   - **Детерминированное планирование**: Создает детальный план рефакторинга на основе полного понимания кода
   - **Верификация**: Проектирует стратегию проверки перед началом рефакторинга
   - **Точное выполнение**: Использует LSP и AST-grep для типобезопасных преобразований
   
   **Пример использования**:
   ```
   /refactor "reconstruct Super big AuthService as Multiple services, after consulting with Oracle"
   ```

2. **Исправление миграции разрешений** (#532)
   - Исправлена миграция разрешений для Claude Code агентов
   - Теперь корректно обрабатываются настройки разрешений

## 🚀 Что делать дальше

1. **Перезапустите OpenCode** (если он запущен):
   - Закройте текущую сессию OpenCode
   - Запустите заново: `opencode .`

2. **Попробуйте новую команду `/refactor`**:
   - Команда доступна сразу после обновления
   - Используйте для интеллектуального рефакторинга кода

3. **Проверьте работу агентов**:
   - Убедитесь, что все агенты работают корректно
   - Проверьте, что background agents больше не создают рекурсивные subagents
