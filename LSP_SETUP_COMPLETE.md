## 🎨 Как это работает

### Порядок выбора сервера

OpenCode использует следующую логику:

1. **Источник конфигурации** (приоритет):
   - `project` (0) - настройки в `.opencode/oh-my-opencode.json`
   - `user` (1) - настройки в `~/.config/opencode/oh-my-opencode.json` ← **Наш случай**
   - `opencode` (2) - встроенные серверы OpenCode

2. **Приоритет сервера**:
   - Больше = выше приоритет
   - Наши настройки имеют приоритет над встроенными (-100)

3. **Выбор сервера**:
   - OpenCode выбирает первый доступный сервер с наивысшим приоритетом
   - Проверяет установку команды перед использованием

### Примеры работы

#### TypeScript проект
```
Файл: src/index.ts
→ typescript (priority: 10) - языковые функции
→ eslint (priority: 5) - линтинг
```

#### Go проект
```
Файл: main.go
→ gopls (priority: 10) - языковой сервер
```

#### Rust проект
```
Файл: src/lib.rs
→ rust (priority: -100, но единственный для .rs) - языковой сервер
```

#### Deno проект (с deno.json)
```
OpenCode автоматически активирует deno, даже если он отключен в конфиге
→ deno - для Deno runtime
```
