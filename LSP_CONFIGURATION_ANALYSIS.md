## 🔍 Анализ конфликтов

### Приоритеты и порядок выбора

OpenCode использует следующую логику выбора сервера:
1. **Источник конфигурации**: `project` (0) > `user` (1) > `opencode` (2)
2. **Приоритет**: Больше = выше приоритет (сортировка по убыванию)
3. **Встроенные серверы**: Имеют priority: -100 по умолчанию

### Потенциальные конфликты

1. **typescript vs deno**:
   - ✅ **Нет конфликта**: deno активируется только если обнаружен `deno.json` в проекте
   - OpenCode автоматически определяет тип проекта

2. **eslint vs oxlint vs biome**:
   - ⚠️ **Потенциальный конфликт**: Все три являются линтерами
   - **Решение**: Использовать только один линтер на проект
   - **Рекомендация**: eslint (наиболее популярный и совместимый)

3. **typescript + eslint**:
   - ✅ **Нет конфликта**: typescript для языковых функций, eslint для линтинга
   - Работают вместе без проблем

## ✅ Рекомендуемая конфигурация

### Стратегия

1. **TypeScript/JavaScript**:
   - `typescript`: Приоритет 10 (основной языковой сервер)
   - `eslint`: Приоритет 5 (линтинг, если есть в проекте)
   - `deno`: Отключен (активируется автоматически OpenCode при наличии deno.json)
   - `oxlint`: Отключен (используем eslint)
   - `biome`: Отключен (используем eslint)

2. **Rust**:
   - `rust`: Работает автоматически (rust-analyzer установлен)

3. **Go**:
   - `gopls`: Приоритет 10 (установлен в `/Users/r2d2/go/bin/gopls`)

### Приоритеты

- **10**: Основные языковые серверы (typescript, gopls)
- **5**: Вспомогательные инструменты (eslint для линтинга)
- **-100**: Встроенные серверы OpenCode (используются если не переопределены)

## 📝 Конфигурация для oh-my-opencode.json

```json
{
  "lsp": {
    "typescript": {
      "priority": 10,
      "extensions": [".ts", ".tsx", ".js", ".jsx", ".mjs", ".cjs", ".mts", ".cts"]
    },
    "eslint": {
      "priority": 5,
      "extensions": [".ts", ".tsx", ".js", ".jsx", ".mjs", ".cjs", ".mts", ".cts", ".vue"]
    },
    "gopls": {
      "priority": 10,
      "extensions": [".go"]
    },
    "deno": {
      "disabled": true
    },
    "oxlint": {
      "disabled": true
    },
    "biome": {
      "disabled": true
    }
  }
}
```

## 🚀 Преимущества этой конфигурации

1. **Четкие приоритеты**: typescript и gopls имеют высокий приоритет
2. **Нет конфликтов**: Отключены конфликтующие линтеры
3. **Гибкость**: eslint работает только если есть в проекте
4. **Автоматизация**: deno активируется автоматически при необходимости
5. **Производительность**: Используется только необходимые серверы
