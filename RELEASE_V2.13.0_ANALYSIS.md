# Анализ релиза v2.13.0 oh-my-opencode

## 📋 Ключевые изменения

### ✅ Новые функции

1. **Maximum Reasoning Effort Mode**
   - Sisyphus & Keyword Detector теперь поддерживают `variant='max'` для максимальной глубины размышлений
   - Agent-aware ultrawork message generation для умной обработки контекста

2. **Улучшения Slash Command**
   - Рефакторинг системы slash команд с поддержкой опций и интеллектуального кэширования
   - Лучшая производительность и расширяемость для кастомных команд

3. **Гибкая конфигурация MCP**
   - `disabled_mcps` теперь принимает любые MCP имена, давая полный контроль над отключением MCP серверов

### 🐛 Исправления ошибок

1. **Gemini Models**: Мигрированы на explicit `antigravity-` prefix для правильной маршрутизации квот
   - **ВАЖНО**: Это может повлиять на нашу конфигурацию!
   - Нужно проверить, требуют ли модели Gemini префикс `antigravity-` в именах

2. **Planner-Sisyphus**: Исправлены проблемы видимости для совместимости с OpenCode 1.1.1

3. **Keyword Detector**: Правильная передача параметров агента и генерация

### ⚡ Производительность

1. **Параллелизация запуска**: Загрузка команд и навыков теперь выполняется параллельно, уменьшая время запуска
2. **Async-First Loaders**: Миграция на асинхронные паттерны для более плавной инициализации

### 🔧 Обслуживание

1. **Удален `websearch_exa` как built-in MCP сервер**
   - ✅ Мы его уже отключили в `disabled_mcps`, так что это нормально
   - Если нужен, можно добавить через внешнюю конфигурацию

2. **Обновлен fallback model** на `opencode/glm-4.7-free`

3. **Обновлены версии auth плагинов и документация моделей**

## 🔍 Влияние на нашу конфигурацию

### ✅ Безопасные изменения

1. **`websearch_exa` удален из built-in**
   - Мы уже отключили его: `"disabled_mcps": ["websearch_exa"]`
   - Никаких действий не требуется

2. **`disabled_mcps` теперь принимает любые MCP имена**
   - Наша конфигурация уже корректна
   - Можно использовать для любых MCP серверов

3. **Planner-Sisyphus исправлен**
   - Мы используем Planner-Sisyphus, так что это улучшение для нас

### ⚠️ Требует проверки

1. **Gemini Models с `antigravity-` prefix**
   - В релизе указано: "Migrated to explicit `antigravity-` prefix for proper quota routing"
   - Наши модели Gemini в `opencode.json`:
     - `gemini-3-pro-high`
     - `gemini-3-flash`
   - **Вопрос**: Нужно ли изменить на `antigravity-gemini-3-pro-high` и `antigravity-gemini-3-flash`?

2. **Новая фича `variant='max'` для Sisyphus**
   - Можно использовать для максимальной глубины размышлений
   - **Действие**: Опционально - можно добавить в конфигурацию агента

## 📝 Текущая конфигурация

### Модели Gemini в `opencode.json`:
```json
{
  "provider": {
    "google": {
      "models": {
        "gemini-3-pro-high": { ... },
        "gemini-3-flash": { ... }
      }
    }
  }
}
```

### Агенты в `oh-my-opencode.json`:
```json
{
  "agents": {
    "Sisyphus": {
      "model": "anthropic/claude-opus-4-5-high",
      "temperature": 0.1
    },
    "oracle": {
      "model": "google/gemini-3-pro-high",
      "temperature": 0.2
    },
    "document-writer": {
      "model": "google/gemini-3-flash",
      "temperature": 0.3
    }
  }
}
```
