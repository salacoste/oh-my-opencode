# Planner-Sisyphus: Краткое руководство

## ✅ Что уже сделано

Planner-Sisyphus настроен и добавлен в конфигурацию с Thinking Mode!

## 📋 Что такое Planner-Sisyphus?

**Planner-Sisyphus** - это специализированный агент планирования, который:

- ✅ **Анализирует задачи** и создает детальные планы работ
- ✅ **Собирает контекст** через explore и librarian агентов
- ✅ **Работает в READ-ONLY режиме** - не может редактировать файлы
- ✅ **Использует Thinking Mode** для лучшего планирования

## 🎯 Как он работает?

### Workflow:

1. **Пользователь запрашивает задачу**
2. **Planner-Sisyphus активируется** (автоматически или по команде)
3. **Сбор контекста**:
   - Исследует кодовую базу через `explore`
   - Ищет документацию через `librarian`
4. **Создание плана**:
   - Анализирует требования
   - Разбивает на подзадачи
   - Сохраняет план в `.sisyphus/plans/`
5. **Пользователь проверяет план**
6. **Sisyphus выполняет план** (после одобрения)

## ⚙️ Текущая конфигурация

```json
{
  "agents": {
    "Planner-Sisyphus": {
      "model": "anthropic/claude-opus-4-5-high",
      "temperature": 0.1
    }
  }
}
```

- **Модель**: Claude Opus 4.5 High (thinking включен)
- **Temperature**: 0.1 (низкая для точности)
- **Режим**: READ-ONLY (только планирование, не редактирование)

## 🚀 Как использовать?

### 1. Автоматическое использование

Planner-Sisyphus автоматически активируется, когда:
- Запрашивается планирование задачи
- Sisyphus определяет, что нужен детальный план

### 2. Явный запрос

Просто попросите создать план:
```
Создай план для добавления новой функции авторизации
```

### 3. Команда /plan

Используйте команду `/plan` в OpenCode для активации режима планирования.

## 📝 Что может Planner-Sisyphus?

### ✅ Может:
- Читать файлы для анализа
- Использовать explore для поиска в кодовой базе
- Использовать librarian для поиска документации
- Создавать планы в `.sisyphus/plans/` и `.sisyphus/drafts/`
- Задавать уточняющие вопросы

### ❌ Не может:
- Редактировать файлы (кроме `.sisyphus/`)
- Выполнять bash команды (только read-only)
- Реализовывать код
- Делать коммиты

## 🔍 Проверка работы

### 1. Проверьте конфигурацию

```bash
cat ~/.config/opencode/oh-my-opencode.json | grep -A 3 "Planner-Sisyphus"
```

Должно быть:
```json
"Planner-Sisyphus": {
  "model": "anthropic/claude-opus-4-5-high",
  "temperature": 0.1
}
```

### 2. Перезапустите OpenCode

После обновления конфигурации перезапустите OpenCode.

### 3. Протестируйте

Запросите планирование:
```
Создай план для рефакторинга функции авторизации
```

Planner-Sisyphus должен:
- Проанализировать задачу
- Собрать контекст
- Создать детальный план
- НЕ пытаться редактировать файлы

## 💡 Преимущества Thinking Mode

1. **Более глубокий анализ** - лучшее понимание сложных задач
2. **Лучшее планирование** - более структурированные планы
3. **Учет зависимостей** - понимание связей между задачами
4. **Предвидение проблем** - выявление проблем до реализации

## ⚙️ Настройка (опционально)

### Изменить модель

Если хотите использовать другую модель:

```json
{
  "agents": {
    "Planner-Sisyphus": {
      "model": "anthropic/claude-sonnet-4-5-high",
      "temperature": 0.1
    }
  }
}
```

### Отключить Planner-Sisyphus

```json
{
  "sisyphus_agent": {
    "planner_enabled": false
  }
}
```
