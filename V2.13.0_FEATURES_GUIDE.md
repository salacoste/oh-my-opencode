# Руководство по использованию новых функций v2.13.0

## 🎯 Новые функции и их применение

### 1. Maximum Reasoning Effort Mode (`variant='max'`)

**Что это**: Максимальная глубина размышлений для Sisyphus и Keyword Detector.

**Как работает**:
- Активирует максимальный режим reasoning для более глубокого анализа
- Agent-aware ultrawork message generation для умной обработки контекста
- Особенно полезно для сложных задач, требующих глубокого размышления

**Как применить в вашей конфигурации**:

#### Вариант 1: Для Sisyphus (рекомендуется)
```json
{
  "agents": {
    "Sisyphus": {
      "model": "anthropic/claude-opus-4-5-high",
      "temperature": 0.1,
      "variant": "max"
    }
  }
}
```

#### Вариант 2: Для Planner-Sisyphus (для сложного планирования)
```json
{
  "agents": {
    "Planner-Sisyphus": {
      "model": "anthropic/claude-opus-4-5-high",
      "temperature": 0.1,
      "variant": "max"
    }
  }
}
```

**Когда использовать**:
- ✅ Сложные архитектурные решения
- ✅ Многоэтапные задачи с множеством зависимостей
- ✅ Критически важные проекты, требующие максимальной точности
- ⚠️ Увеличивает время ответа и потребление токенов

### 2. Улучшения Slash Command

**Что это**: Рефакторинг системы slash команд с поддержкой опций и интеллектуального кэширования.

**Преимущества**:
- Лучшая производительность команд
- Поддержка опций для кастомных команд
- Интеллектуальное кэширование результатов

**Как использовать**:
- Автоматически активировано после обновления
- Не требует изменений в конфигурации
- Улучшает работу всех встроенных и кастомных команд

**Примеры улучшенных команд**:
- `/plan` - теперь работает быстрее с кэшированием
- `/build` - улучшенная обработка опций
- Кастомные команды - поддержка параметров

---

### 3. Гибкая конфигурация MCP

**Что это**: `disabled_mcps` теперь принимает любые MCP имена.

**Текущая конфигурация** (уже корректна):
```json
{
  "disabled_mcps": ["websearch_exa"]
}
```

**Новые возможности**:
```json
{
  "disabled_mcps": [
    "websearch_exa",
    "context7",           // Можно отключить любой MCP
    "grep_app",           // Даже встроенные
    "custom-mcp-server"   // Или кастомные
  ]
}
```

**Преимущества**:
- Полный контроль над MCP серверами
- Можно отключать любые серверы, не только встроенные
- Гибкая настройка под конкретные проекты

---

### 4. Исправления Gemini Models (antigravity- prefix)

**Что изменилось**: Модели Gemini мигрированы на explicit `antigravity-` prefix для правильной маршрутизации квот.

**Текущая конфигурация**:
```json
{
  "provider": {
    "google": {
      "models": {
        "gemini-3-pro-high": { ... },
        "gemini-3-flash": { ... }
      }
    }
  }
}
```

**Если модели не работают, обновите на**:
```json
{
  "provider": {
    "google": {
      "models": {
        "antigravity-gemini-3-pro-high": {
          "name": "Gemini 3 Pro High (via Antigravity)",
          "thinking": true,
          "attachment": true,
          "limit": { "context": 1048576, "output": 65535 },
          "modalities": { "input": ["text", "image", "pdf"], "output": ["text"] }
        },
        "antigravity-gemini-3-flash": {
          "name": "Gemini 3 Flash (via Antigravity)",
          "attachment": true,
          "limit": { "context": 1048576, "output": 65536 },
          "modalities": { "input": ["text", "image", "pdf"], "output": ["text"] }
        }
      }
    }
  }
}
```

**И обновите агентов**:
```json
{
  "agents": {
    "oracle": {
      "model": "google/antigravity-gemini-3-pro-high",
      "temperature": 0.2
    },
    "document-writer": {
      "model": "google/antigravity-gemini-3-flash",
      "temperature": 0.3
    },
    "frontend-ui-ux-engineer": {
      "model": "google/antigravity-gemini-3-pro-high",
      "temperature": 0.2
    },
    "multimodal-looker": {
      "model": "google/antigravity-gemini-3-flash",
      "temperature": 0.1
    }
  }
}
```

**Действие**: Протестировать после перезапуска. Если модели не работают - добавить префикс.
